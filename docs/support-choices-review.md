# 쓰기 도움 낱말 보기 검토표

각 칸의 **굵은 글씨**가 자료에 맞는 보기, 나머지 둘은 다른 주제 자료에서 가져온 보기예요. 학생 화면에서는 순서를 섞어서 보여 줘요.

고칠 곳이 있으면 자료 이름과 바꿀 문장을 알려 주세요. 실제 데이터는 `support-data.js`에 있어요.
